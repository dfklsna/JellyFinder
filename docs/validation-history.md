## 재현성에 관한 미해결 사항

원본 설명과 메타데이터는 Python 3.12.13을 가리키지만, 셀 출력은 Python 3.13.15를 기록합니다. NumPy도 메타데이터는 2.5.3, 셀 출력은 2.1.3입니다. 정리본의 요구 패키지 목록과 이 기록은 **셀 출력**을 기준으로 삼았습니다. 기존 메타데이터의 PASS·fresh-kernel 표시는 새 노트북에 복사하지 않았습니다.

원본 출력의 `pip check`에는 다음 문제가 남아 있습니다.

- `ipython 7.34.0`이 요구하는 `jedi` 누락
- `google-colab 1.0.0`의 `requests==2.32.4` 요구와 설치된 `requests==2.34.2` 충돌

기능 평가 PASS와 의존성 충돌 해결은 별개입니다. 새 가상환경에서 의존성 설치·검사와 전체 API 평가를 다시 수행해야 정리본의 실행을 검증할 수 있습니다. Gradio는 `>=5,<7` 범위만 남아 있으며 과거의 정확한 설치 버전과 UI 검증 기록은 없습니다.
